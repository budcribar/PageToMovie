HARD RULES
- Cover the ENTIRE book. Missing a major episode is a defect.
- There is NO scene-count maximum. A long novel may have 80–200 cards. Err long.
- Do not collapse voyages, underworld, or other set pieces into a single montage card.
- Every card needs: unique id, order, heading, location_key, beat, book_anchor_start, book_anchor_end.
- heading is INT./EXT. + a concrete filmable place. DAY/NIGHT optional if unknown.
- location_key is a stable Loc_* token. Same place = same key.
- speaking_cast uses ALL-CAPS character tokens. Same person = same token.
- book anchors must be verbatim excerpts from the attached book (not summaries).
- Sequence titles name the story unit (Cyclops, Circe, Bow contest), not "chunk 3".
- Unique ids across acts, sequences, and scenes.
- approx_minutes is a rough screen time hint, not a cap.

The attached file is the full book. Index that file.
