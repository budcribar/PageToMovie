# labMode (2026-08-05)

Experimental catalog rows that are intentionally incomplete.

```json
"labMode": true,
"labNotes": "Why this model is incomplete / what is under test"
```

## Rules
| Area | Behavior |
|------|----------|
| **Self-test** | Only requires id, displayName, and non-empty `labNotes` |
| **Production models** | `labMode` false/omitted — full required fields |
| **Cost** | Missing rates → `$0` with `pricing_source: lab_mode` (not invented vendor prices) |
| **UI** | Configuration dropdowns show `[LAB]`; Admin catalog shows **LAB** badge |
| **Admin** | New models default to lab mode; clear after Review + fill real fields |

Runtime still fails on a **specific** missing capability field when a job actually needs it (e.g. duration bounds for video gen).


## Access control (2026-08-05)
- **Lab models are admin-only.**
- `/api/models` and `/api/models/catalog-json` omit `labMode: true` rows unless the caller is admin.
- Configuration dropdowns hide lab models for non-admins.
- Non-admin config save rejects lab model ids.
- Film jobs refuse lab models for non-admin users.
- Only `/admin/models-catalog` can set `labMode` (admin session required).
